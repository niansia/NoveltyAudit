# Security and privacy

Please report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature when enabled. Do not open a public issue containing credentials, private manuscripts, unpublished claims, or exploitable details.

NoveltyAudit sends minimized queries to configured scholarly providers. It does not require manuscript uploads, does not collect telemetry, and stores no cloud-side audit history. Users remain responsible for reviewing provider privacy terms and keeping API keys out of commits.

Supported security fixes target the latest release. A report should include the affected version, reproduction steps, impact, and a suggested mitigation when known.
