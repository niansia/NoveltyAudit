# Deterministic tooling

Before running helpers, verify Python 3.10+ and install `requirements.txt` when package installation is permitted. If `jsonschema` is unavailable, deterministic report validation is unavailable. If `pypdf` is unavailable, PDF Tier-2 extraction is unavailable. Do not silently skip either capability: disclose the limitation and mark the run `PARTIAL` or the conclusion `INCONCLUSIVE` as appropriate.

Run commands from the user's working directory. Set the skill path explicitly when useful:

```text
python <skill>/scripts/cli.py search --provider openalex --family mechanism --query "..." --before 2025-09-18 --output candidates.json
python <skill>/scripts/cli.py search-plan --input query-plan.json --output candidates.json
python <skill>/scripts/cli.py dedupe --input candidates.json --output canonical.json
python <skill>/scripts/cli.py dates --input canonical.json --cutoff 2025-09-18 --output dated.json
python <skill>/scripts/cli.py fetch-fulltext --papers dated.json --paper-id W123 --output-dir fulltext --manifest fulltext-manifest.json
python <skill>/scripts/cli.py mps --input report-draft.json --output mps.json
python <skill>/scripts/cli.py graph-preflight --papers dated.json --paper-a W123 --paper-b W456 --cutoff 2025-09-18 --output graph-preflight.json
python <skill>/scripts/cli.py expand-graph --papers dated.json --paper-a W123 --paper-b W456 --cutoff 2025-09-18 --limit 100 --output expanded.json
python <skill>/scripts/cli.py bridge --papers canonical.json --paper-a W123 --paper-b W456 --cutoff 2025-09-18 --output bridges.json
python <skill>/scripts/cli.py verify-citations --input report.json --output report.verified.json
python <skill>/scripts/cli.py report-attempt --input report.verified.json --output report.bound.json --max-attempts 3 --state report-assembly.json
python <skill>/scripts/cli.py validate --input report.bound.json
python <skill>/scripts/cli.py export --input report.bound.json --format markdown --output report.md
python <skill>/scripts/cli.py snapshot-diff --before previous-report.json --after current-report.json --output diff.json
```

`query-plan.json` contains an explicit `cutoff`, per-page candidate `limit`, optional `max_pages` (default 10), provider list, and canonical queries. Every query supplies `query_id`, `family`, `query`, `reason`, `target_facets`, and `removed_author_terms`; a query may explicitly set `temporal_recall_backstop: true`. If none does, `search-plan` deterministically chooses the first ancestor query, or the first query when no ancestor query exists. That run bypasses provider-side cutoff pushdown, records `temporal_recall_backstop=true` and `provider_cutoff_applied=false`, and leaves final eligibility to downstream date resolution. Each SearchRun records aggregate counts, every page response, provider `total_count`, `truncated`, `corpus`, raw and canonical paper IDs, and a `saturation_stop_reason`: `PROVIDER_EXHAUSTED`, `NO_NEW_RESULTS`, `PAGE_BUDGET_EXHAUSTED`, or `PROVIDER_ERROR`. For arXiv, `raw_returned_count`, `eligible_returned_count`, and the next raw offset prevent locally filtered pages from becoming fake saturation. The command returns `COMPLETE`, `PARTIAL`, or `FAILED`, structured provider failures, canonical candidates, and a deterministic coverage derivation.

Search Protocol Coverage is not a model judgment and is not a recall estimate. It is derived only from SearchRun records. `BROAD` means that the bounded protocol was executed broadly; it does not demonstrate that every relevant paper was retrieved. `BROAD` requires complete run metadata, at least two successful providers, every required query family, no failed or truncated run, a saturation stop for every successful run, all search obligations complete, and `corpus=all` for every OpenAlex run. The machine derivation records `scope=PROTOCOL_EXECUTION_NOT_RECALL`, and the validator independently recomputes both `search.saturated` and the coverage level.

Primary retrieval providers are OpenAlex, Semantic Scholar, and arXiv. Crossref is used only for DOI and metadata verification, not as a primary semantic search source. API keys are optional for basic use; Semantic Scholar accepts `S2_API_KEY`, and a free `OPENALEX_API_KEY` raises the OpenAlex daily API budget from the anonymous trial allowance to $1/day. OpenAlex retired the polite-pool system in 2026, so `mailto` is not sent. NoveltyAudit explicitly requests OpenAlex `corpus=all`; set `OPENALEX_CORPUS=core` or `expansion` only when intentionally narrowing the run, which prevents a `BROAD` classification.

The scripts never call an LLM. They normalize records, resolve dates, deduplicate versions, acquire and extract provider-derived public full text, discover graph candidates, solve MPS, validate invariants, and render reports. `fetch-fulltext` accepts only public HTTP(S) sources, rejects embedded credentials, validates every resolved address, connects directly to one of those pinned addresses while preserving the hostname for HTTP Host/TLS SNI, rejects an unvalidated or non-public actual peer, and re-applies the same rules after redirects. Environment HTTP proxies are disabled for this path so they cannot bypass peer validation. It also limits response size, extracts PDF/HTML/text, writes text to the user's output directory, and records content/text hashes. Acquisition does not interpret evidence; the host agent remains responsible for facet decomposition and evidence interpretation. Tier-2 evidence must reference a matching successful acquisition ID.

`runtime-info` is an optional diagnostic that prints the actual Python, `jsonschema`, and `pypdf` versions resolved in the execution environment. The report workflow does not trust a host to copy this object: `report-attempt` injects it itself.

`report-attempt` is the host-neutral assembly gate. `--input`, `--output`, and `--state` must be three different paths. Use a fixed budget of at most three attempts and reuse the same `--state` path after each repair. It replaces any host-supplied `run_manifest.runtime_environment` with the versions resolved by its own process before validation and canonical report hashing, writes that exact machine-bound report to `--output`, and verifies the written file against the state hash. Every attempt records `runtime_binding=MACHINE_INJECTED_BEFORE_VALIDATION_AND_HASH` plus the resolved environment. Earlier binding records participate in the same internal state-consistency checks as the immutable identity made from `audit_id`, `claim_map.claim_id`, `claim_map.freeze_hash`, and `run_manifest.cutoff`; a state from another audit is rejected. A missing history cannot claim exhaustion, and a terminal state cannot be overwritten by another attempt. A valid draft returns `COMPLETE` with `next_action=EXPORT_MACHINE_BOUND_REPORT`; export only its bound output. An invalid draft before the final attempt returns `RETRY_REQUIRED`; repair the bound output and retry using a different input/output pair. An invalid final attempt returns terminal `PARTIAL`, `retry_exhausted=true`, and `conclusion_cap=INCONCLUSIVE`. The command never repairs semantic/model output; runtime binding is its only automatic report mutation. Standalone `validate` checks a historical runtime record's structure but does not compare it with the later reviewer machine.

`graph-preflight` is a local, zero-network observation-window diagnostic to run before graph retrieval. It calculates the days from the newer endpoint's verified earliest public date to the cutoff and labels the pair `BELOW_DIAGNOSTIC_THRESHOLD` or `MEETS_DIAGNOSTIC_THRESHOLD` against the exploratory 548-day threshold. The threshold comes from the dated 82-case snapshot; the latter status does not establish field maturity, and neither status is a reason to skip retrieval or a universal law.

`expand-graph` is the active citation-chasing stage. By default it uses every available OpenAlex and Semantic Scholar ID: backward records are unioned across all endpoint/provider routes, while forward co-citation candidates are unioned across provider namespaces carried by both endpoints. `--provider` is available for diagnostics or a deliberately scoped retry. If no namespace spans both endpoints, available backward records are preserved but forward expansion is recorded as a provider failure and the result is `PARTIAL`, not an exception or a complete zero. Calls and `provider_observations` are provider-attributed. Graph calls omit provider-side date filtering, admit a third paper only when its returned references contain the other endpoint in the same namespace, merge records into `papers`, and apply the local earliest-public-date resolver. The expansion requires `temporal_recall_backstop=true` for historical runs and `provider_cutoff_applied=false`. Each call records its limit, exhaustion state, continuation token, provider/raw counts, and `possibly_truncated`; incomplete traversal fails closed. The output partitions historical from landscape candidates and records the preflight-derived observation-window status and negative-result scope; the validator recomputes them from calls and candidate dates.

`bridge` defaults to a 500-citation endpoint guard. The public 82-case sensitivity table varied the threshold from 50 to 1,000 and observed pair rates from 8.47% to 12.12%, so v0.3.1 labels this policy `SENSITIVITY_CHECKED`, not universally calibrated. A custom threshold plus `--bridge-policy-source` is emitted as `DOCUMENTED_OVERRIDE`. `CALIBRATION_DECLARED` additionally requires `--calibration-dataset`, `--calibration-method`, and `--calibration-preregistered`; this is structured calibration provenance, not machine verification that an artifact exists or supports the threshold.

Graph expansion is a conditional audit obligation, not an optional claim. For every recomputed MPS with two or more papers, all endpoint combinations must appear as `COMPLETE` records in `search.graph_expansions`. Missing and `PARTIAL` pairs cannot support a negative bridge finding: the verdict must be `INCONCLUSIVE`, and `search.gaps` must contain `GRAPH_EXPANSION_INCOMPLETE:<smaller-paper-id>:<larger-paper-id>` for each incomplete pair. Paper IDs are sorted lexicographically when constructing this marker.
