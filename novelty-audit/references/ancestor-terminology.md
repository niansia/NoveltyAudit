# Ancestor terminology

Use this route when a claim contains recent branding, a compound phrase, or terminology that may hide older functional equivalents.

1. Rewrite the term as a plain functional description.
2. Search older surveys, reference chains, taxonomies, and foundational papers.
3. Admit an ancestor term only when a real source uses it and an evidence span supports the relationship.
4. Record the source paper, earliest public date, evidence location, relation (`equivalent`, `broader`, `narrower`, or `adjacent`), and rationale.
5. Re-run retrieval with admitted ancestor terms.

An LLM-proposed term without provenance is an exploratory query only. It must not appear in the formal terminology trail.
