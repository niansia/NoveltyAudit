# Privacy model

Treat unpublished ideas and manuscripts as private by default.

- Perform claim decomposition and report generation locally in the host agent.
- Send minimized search queries, not the full manuscript, to scholarly APIs.
- Before using an optional full-text or LLM service that receives manuscript content, identify the provider and obtain authorization.
- Do not collect telemetry by default.
- Keep caches local, configurable, and removable; do not place private inputs in public demos.
- Public benchmark and demo material must come from publicly available papers and reviews with traceable licensing.
